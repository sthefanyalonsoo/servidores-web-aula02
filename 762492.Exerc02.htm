Identificar Cliente, Servidor e Resposta

Site escolhido: YouTube

URL acessada: https://www.youtube.com/
YouTube

Cliente: O cliente é o computador ou celular do usuário, juntamente com o navegador utilizado para acessar o site, como Chrome.

Servidor: O servidor é o sistema do YouTube responsável por receber as solicitações do cliente e fornecer os conteúdos solicitados.

Resposta do servidor: O servidor entrega ao cliente os arquivos e dados necessários para carregar a página do YouTube, como textos, imagens, vídeos e outros recursos.

Protocolo utilizado: HTTPS
