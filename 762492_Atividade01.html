Tipos de Servidores

Nesta atividade, serão apresentados alguns cenários e, para cada um deles, será identificado o tipo de servidor mais adequado, juntamente com a justificativa da escolha.

1. Blog de notícias

Servidor Web

Eu utilizaria um servidor web para um blog de notícias, pois ele é responsável por armazenar e disponibilizar páginas para os usuários através da internet. Dessa forma, quando uma pessoa acessar o blog, o servidor poderá entregar as páginas, imagens e outros conteúdos necessários para a visualização das notícias.

2. Sistema bancário

Servidor de Aplicação

Eu utilizaria um servidor de aplicação para um sistema bancário, pois esse tipo de servidor consegue executar as regras e operações do sistema. Em um banco, é necessário realizar operações como transferências, pagamentos e consultas de saldo, que precisam ser processadas de forma segura e controlada.

3. Compartilhamento de arquivos internos de uma empresa

Servidor de Arquivos

Eu utilizaria um servidor de arquivos porque ele é desenvolvido justamente para armazenar e compartilhar arquivos entre os computadores de uma rede. Assim, os funcionários poderiam acessar documentos da empresa de acordo com as permissões definidas para cada usuário.

4. Plataforma de vídeos sob demanda

Servidor de Streaming

Eu utilizaria um servidor de streaming para uma plataforma de vídeos sob demanda, pois ele permite transmitir vídeos pela internet sem que o usuário precise baixar o arquivo inteiro antes de começar a assistir. Isso facilita o acesso aos conteúdos e permite que várias pessoas assistam aos vídeos pela plataforma.
