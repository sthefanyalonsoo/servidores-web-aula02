## Resumo da aula

Nesta aula, aprendemos conceitos básicos sobre servidores web e como acontece a comunicação entre cliente e servidor. Também identificamos a diferença entre servidor local e servidor remoto, além de compreender os ambientes de desenvolvimento e produção.

## O que aprendi sobre servidores web

Aprendi que o cliente é responsável por fazer uma solicitação ao servidor, enquanto o servidor recebe essa solicitação e retorna uma resposta. Também aprendi a diferença entre um servidor local, utilizado no próprio computador, e um servidor remoto, que pode ser acessado pela internet.

Além disso, compreendi que o ambiente de desenvolvimento é utilizado para criar e testar sistemas, enquanto o ambiente de produção é onde o sistema fica disponível para os usuários.
